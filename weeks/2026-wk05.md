**Process lessons for Week 6:**
1. GPP lineups need real **game stacks** (QB + 2 pass catchers + bring-back) as
   the default, not a 1-in-3 chance. The GB stack would have been 26 + 35 + 21.
2. Run the **inactive check** before lock and swap any OUT player. It would have
   saved two lineups.
3. Spread the 8/30 cap more evenly. Five "core" players at 8/30 left too
   little room for the leverage plays that won the slate.
