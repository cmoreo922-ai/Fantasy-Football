# Season-Long Scoring Formats (PPR / Half-PPR / Standard / Superflex)

DraftKings DFS is **full PPR** (see draftkings-scoring.md). Season-long leagues
vary — always check your league settings, because format changes who's valuable.

## Shared base (nearly every league)

- 1 pt per 10 rushing/receiving yards
- 1 pt per 25 passing yards
- 6 pts rushing/receiving TD, 4 pts passing TD
- −2 INTs/fumbles lost (typical; DK uses −1)

## The reception rule is the fork

| Format | Per catch | Who gains value |
|---|---|---|
| **Standard** | 0 | TD scorers, workhorse rushers; very TD-dependent (a TD = 60 yds) |
| **Half-PPR** | 0.5 | Balanced — the modern default for many leagues |
| **Full PPR** | 1.0 | Slot WRs, possession receivers, pass-catching RBs; volume rules |

Practical shifts as PPR increases: pass-catching RBs jump entire tiers;
high-target, low-aDOT WRs (slot guys) become weekly starters; deep-threat
boom/bust WRs fall; TEs with real target shares gain.

## Superflex (roster rule, not scoring)

Adds a flex slot that can hold a **QB**. Since QBs outscore everyone, a 12-team
superflex league needs ~24 startable QBs — even QB16 has real value. Draft QBs
early and hoard them; never enter a superflex week with an empty superflex slot.

## Other common wrinkles to check in any league

- **TE premium** (1.5 PPR for TEs): elevates elite TEs to WR1-level assets
- **Bonuses** (100/300-yd): favors ceiling players, like DK
- **6-pt passing TDs:** elite QBs jump a full round in value
- **IDP, kickers, return yards:** niche — ask before drafting
