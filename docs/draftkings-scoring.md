# DraftKings NFL Scoring — Complete Reference

Source: DraftKings official NFL rules (draftkings.com/help/rules/1/96), cross-checked
against third-party scoring references. DK scoring has been stable for years, but
re-verify at the start of each season.

## Classic contests — roster and salary

- **Roster:** 1 QB, 2 RB, 3 WR, 1 TE, 1 FLEX (RB/WR/TE), 1 DST — 9 spots
- **Salary cap:** $50,000
- Players from at least **2 different NFL games** required
- No kickers in Classic

## Offensive scoring

| Event | Points |
|---|---|
| Passing yard | +0.04 (1 pt per 25 yds) |
| Passing TD | +4 |
| **300+ passing yards bonus** | **+3** |
| Interception thrown | −1 |
| Rushing yard | +0.1 (1 pt per 10 yds) |
| Rushing TD | +6 |
| **100+ rushing yards bonus** | **+3** |
| Receiving yard | +0.1 |
| **Reception (full PPR)** | **+1** |
| Receiving TD | +6 |
| **100+ receiving yards bonus** | **+3** |
| Punt/Kickoff/FG return TD | +6 |
| Fumble lost | −1 |
| 2-pt conversion (score or throw) | +2 |
| Offensive fumble recovery TD | +6 |

## DST scoring

| Event | Points |
|---|---|
| Sack | +1 |
| Interception | +2 |
| Fumble recovery | +2 |
| Defensive/return TD (any kind) | +6 |
| Safety | +2 |
| Blocked kick | +2 |
| 2-pt conversion / XP return | +2 |

**Points allowed** (only counts points surrendered while the DST is on the field —
pick-sixes thrown by your own offense don't count against your DST):

| Points allowed | DST points |
|---|---|
| 0 | +10 |
| 1–6 | +7 |
| 7–13 | +4 |
| 14–20 | +1 |
| 21–27 | 0 |
| 28–34 | −1 |
| 35+ | −4 |

## Showdown (single-game) contests

- **Roster:** 1 Captain (CPT) + 5 FLEX, all from one game, $50,000 cap
- Captain costs **1.5× salary** and scores **1.5× points**
- Must roster at least one player from each team
- Kickers ARE in the Showdown player pool

## What DK scoring rewards (strategy implications)

1. **Full PPR + yardage bonuses = volume and big games rule.** A reception is
   worth 10 receiving yards. High-target pass catchers (slot WRs, pass-catching
   RBs) have raised floors on DK vs. other sites.
2. **The +3 bonuses matter at the margins.** DK deliberately rewards ceiling
   games: a 105-yard rusher outscores a 95-yard rusher by 4 pts, not 1. Favor
   players with true 100-yd/300-yd upside — workhorse RBs, alpha WRs, high-volume QBs.
3. **Pass-catching RBs are gold.** They combine rushing yards, receptions, and
   receiving yards — three scoring streams plus two possible bonuses.
4. **Rushing QBs have the highest ceilings.** Rush yards score 2.5× pass yards
   per yard, and rushing TDs are worth 6 vs 4. A QB with a 40-yd rushing floor
   effectively starts with +4 points.
5. **INTs are cheap (−1).** Don't overly fade aggressive QBs; a pick costs one
   point but the aggression produces TDs.
6. **DSTs swing on sacks + turnovers, not just points allowed.** The gap between
   allowing 20 and 21 points is just 1 pt; a 4-sack, 2-turnover game is 8 pts.
   Target defenses facing bad offensive lines and turnover-prone/rookie QBs,
   especially as big home favorites (opponent forced to pass while trailing).
